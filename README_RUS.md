# Генерация и детекция геометрических фигур с дообучением модели

## 📌 Описание проекта

Проект посвящён исследованию задачи **детекции простых геометрических фигур** на синтетических изображениях с использованием нейросетевой модели **RetinaNet (ResNet50-FPN)**.

Основная цель — изучить поведение модели при **дообучении новому классу (hexagon)** и проанализировать влияние *incremental learning* на качество распознавания старых классов (**catastrophic forgetting**).

---

## 🎯 Основные задачи проекта

1. **Генерация данных**
    - Синтетическая генерация изображений `256×256` с 1–5 случайными фигурами.
    - Поддерживаемые классы: `triangle`, `rhombus`, `circle`, `hexagon`.
    - Аннотации сохраняются в формате JSON (bounding boxes + метаданные).
    - Также реализована **распределённая генерация на Apache Spark** для ускорения.
2. **Обучение модели**
    - Базовая модель: **RetinaNet (ResNet-50 FPN)** из `torchvision`.
    - Аугментации через **Albumentations**: повороты, отражения, размытие, изменение контраста.
    - Метрики: `Precision@0.5`, `Recall@0.5`, `Mean IoU`.
    - Визуализация предсказаний и метрик с помощью `Matplotlib` и `Seaborn`.
3. **Дообучение модели (Incremental Learning)**
    - Введение нового класса: **hexagon**.
    - На каждой итерации:
        1. Тестирование на двух выборках:
            - `Test1` — без hexagon
            - `Test2` — с обязательным включением hexagon
        2. Добавление 400 новых изображений с hexagon.
        3. Дообучение модели в течение 5 эпох.
    - Всего 20 итераций, анализ динамики метрик и распределения классов.
4. **Отчёт**
    - Подробный анализ результатов (графики, таблицы, визуализации).
    - Выводы о стабильности модели и проблеме «забывания» старых классов.

## 🚀 Запуск проекта

1. **Клонировать репозиторий**
    
    ```bash
    git clone https://github.com/captaink21/ShapeDetection.git
    cd ShapeDetection
    ```
    
2. **Сгенерировать данные**
    
    ```bash
    python spark_generate.py
    ```
    
    или локально (без Spark):
    
    ```bash
    python generate_splits.py
    ```
    
3. **Запустить обучение**
    
    ```bash
    python task_3.py
    
    ```
    
4. **Посмотреть результаты**
    
    ```
    /output/
    ├── task3_results.json
    ├── task3_metrics_curve.png
    ├── task3_metrics_seaborn.png
    ├── task3_iou_boxplot.png
    ├── task3_metrics_correlation.png
    └── train_class_distribution.json
    
    ```
